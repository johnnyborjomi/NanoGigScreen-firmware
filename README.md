# NanoGig Screen firmware

Release builds of [NanoGig Screen](https://github.com/johnnyborjomi/NanoGigScreen), a gig screen for the
Neural DSP Nano Cortex on an ESP32-2432S028 "Cheap Yellow Display". The screen installs the latest
`nanogig_screen.bin` from here by itself: Menu → Settings → page 3 → **Check for updates**.
